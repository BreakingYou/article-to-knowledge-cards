# make-knowledge-cards

把一篇文章变成一叠**可复习的知识卡片**。这是一个 AI Skill（技能包），位于 `skills/make-knowledge-cards/`，不含任何脚本，只有指令文件。

## 解决什么问题

读完一篇文章，要点散落在段落里，记不住、也复习不了。手动整理卡片又费时费力，而且容易出现两个问题：

- **摘要化**：把全文压成一大段，读完还是抓不住单个知识点。
- **失真**：整理过程中悄悄加入了原文没有的结论，复习时把"自己脑补的"当成了"文章讲的"。

这个技能把文章拆成一张张**一卡一个知识点**的卡片，每张卡片只承载一个知识点，并严格约束"卡片内容必须能在原文找到出处"——信息不足时就少出几张，绝不编造、不凑数。

## 主要功能

| 功能 | 说明 |
| --- | --- |
| 提炼知识卡片 | 把粘贴的文本或本地 `.md` / `.txt` 文件提炼成卡片，上限 8 张 |
| 四要素结构 | 每张卡片包含：标题、核心知识、简明解释、例子或自测问题 |
| 一卡一个知识点 | 含两个知识点的候选会被拆开；重复内容被合并，不在卡里堆多个版本 |
| 重要内容筛选 | 按"承载主线、可迁移、有解释力、易混淆"四个信号取舍，丢弃铺垫、情绪、致谢等 |
| 不编造 | 事实、数字、因果必须来自原文；原文没讲机制就明确标注"原文未展开" |
| 数量跟随内容 | 卡片数由知识点数决定：少于 5 张是正常结果，并在末尾说明原因 |
| 自测问题 | 每张卡附带能用原文直接回答的自测问题，便于复习 |

**不支持**：网页抓取、PDF / 图片 / Word 解析、Anki（apkg）导出、图形界面。

## 安装方法

技能是纯指令文件，没有依赖，不需要安装任何软件。把目录复制到你的 skills 目录即可（路径按你使用的客户端调整）：

```bash
cp -r skills/make-knowledge-cards ~/.claude/skills/
```

目录结构：

```
make-knowledge-cards/
├── SKILL.md           # 技能主体：流程、规则、输出格式
└── agents/openai.yaml # 界面元数据（显示名、默认 prompt、触发策略）
```

## 使用方法

复制好后，直接在对话中调用即可。

**方式一：粘贴文章**

```
用 make-knowledge-cards 把下面这段做成知识卡片：

<文章正文>
```

**方式二：指向本地文件**

```
用 make-knowledge-cards 把 notes/睡眠与记忆.md 整理成知识卡片
```

**要求落盘成文件**（可选）：

```
用 make-knowledge-cards 把 notes/睡眠与记忆.md 整理成知识卡片，保存到 knowledge-cards/
```

## 输入输出示例

**输入**（`tech.md` 节选）：

> 在分布式系统中，网络是不可靠的。客户端发出请求后，无法区分"服务端没有收到"和"处理成功但响应丢失"，于是通常只能重试。重试带来一个后果：同一个请求可能被执行多次。所以支付、下单这类接口必须保证幂等……

**输出**：

```markdown
> 主题：网络不可靠导致重试与重复执行，分布式系统需保证幂等

## 卡片 1｜幂等是执行多次与执行一次效果相同

- **核心知识**：重试会让同一请求被执行多次，因此支付、下单等接口必须保证幂等——同一操作执行一次与多次，对系统状态的影响相同。
- **简明解释**：幂等不是"只执行一次"，它允许多次执行，只要求最终状态一致。
- **例子**：支付、下单这类接口必须保证幂等，因为重试会导致同一请求被执行多次。
- **自测**："幂等"和"只执行一次"有什么区别？

## 卡片 2｜幂等键：先查再处理，且必须原子

- **核心知识**：实现幂等的常用办法是幂等键：客户端为每次请求携带全局唯一 ID，服务端处理前先查该 ID 是否已处理，已处理就直接返回上次结果。
- **简明解释**：唯一 ID 的"查询 + 写入"必须是原子操作，否则两个并发的重试请求可能同时通过检查，幂等就失效了。
- **自测**：为什么幂等键的"查询 + 写入"必须是原子操作？
```

**信息不足时**（输入只有一句"多喝水对身体好"），不会硬凑数量：

```markdown
> 主题：原文建议每天多喝水

## 卡片 1｜多喝水有益健康（原文未给依据）

- **核心知识**：原文主张多喝水对身体好，并建议每天多喝水。
- **简明解释**：原文未展开——没有说明"多喝水"的量化标准，也没有给出机制或证据。
- **自测**：原文对日常饮水给出了什么建议？

---
说明：原文有效知识点仅 1 个，故只出 1 张卡；原文更适合摘要而非卡片。
```
